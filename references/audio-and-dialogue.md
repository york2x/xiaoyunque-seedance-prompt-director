# 声音、对白与字幕规则

## 五层声音结构

1. BGM
2. 环境音
3. 动作拟音
4. 对白 / VO
5. 字幕

## BGM

如果需要音乐，写清：

`类型 + 情绪 + 配器/质感 + 音量关系`

例如：

`低音量温暖电影氛围配乐，以柔和钢琴和克制弦乐为主，无明显鼓点，不盖过对白和环境声。`

如果不需要音乐：

`无 BGM，只保留真实环境音、动作音和人物对白。`

## 环境音

环境音写成真实声场，而不是关键词清单。

例如：

`秋日果园保持安静自然的真实环境声，远处偶尔有稀疏鸟鸣，微风经过树冠时出现轻柔叶片摩擦声。`

## 动作拟音

动作与声音绑定：

`机械手伸展时有极轻伺服声；果实脱离枝梗瞬间出现短促枝条回弹与叶片摩擦声。`

## 对白

推荐结构：

`角色 + 表演动作 + 完整台词 + 语言 + 声线 + 情绪 + 语速 + 口型要求`

多人时明确台词归属和顺序，必要时写未说话人物保持闭嘴。

## 字幕

对白和字幕分开控制。

有对白无字幕：

`正常生成对白，不生成任何对白字幕。`

需要字幕时，明确要求字幕内容与对白一致，并避免乱码、错字或额外字幕。

## 混音

对白优先级最高时可写：

`人物说话时 BGM 和环境音自然降低，对白结束后缓慢恢复。`

跨场景可用声音桥：

- J-cut：下一场景声音提前进入
- L-cut：上一场景声音短暂延续
- BGM 连续：场景切换时音乐不中断，只调整强弱或配器
