# Asset Mapping｜参考素材职责映射

本文件只负责参考素材的识别、职责隔离与角色绑定。

通用 Prompt 校验、人物数量、时间轴、镜头冲突、动作物理、声音冲突等检查统一交给 `references/preflight-compiler.md`。

## 核心原则

每个参考素材都要回答四个问题：

1. 它是谁 / 是什么
2. 它的主要职责是什么
3. 允许参考哪些属性
4. 哪些属性禁止迁移

内部优先解析为：

`素材ID → 主要职责 → 允许参考属性 → 禁止迁移属性`

默认优先“一素材一主要职责”。如果一个素材承担多个次要职责，必须明确边界。

## 图片参考

### 人物外观参考

推荐：

`@图片1：主角外观参考；只参考脸型、五官、发型、服装和体型，不参考背景。`

如果图片里还有其他人物：

`不参考图片中的其他人物，不新增角色。`

### 场景参考

推荐：

`@图片2：场景参考；只参考空间结构、构图、植物状态、材质和光影，不参考其中人物。`

### 道具 / 商品参考

推荐：

`@图片3：只参考该道具的形状、颜色、材质、比例和细节，不参考背景与手部。`

## 视频参考

视频默认拆分职责，不直接整段照搬。

### 动作参考

`@视频1：只参考主体动作轨迹、动作速度、节奏和接触关系，不参考人物外观、服装和场景。`

### 运镜参考

`@视频1：只参考机位变化、镜头运动路径、速度和节奏，不参考人物、场景和色彩。`

### 转场参考

`@视频1：只参考转场触发动作和转场形式，不参考角色外观与场景内容。`

如果同一个视频同时参考动作和运镜，需要明确两项都是允许职责，并排除人物外观和场景迁移。

## 音频参考

### 音色

`@音频1：角色1使用该音色，只参考音色、语气和说话质感。`

### 节奏

`@音频2：只参考鼓点、节拍和剪辑节奏，不参考其中人声内容。`

### 环境 / 音效

明确是参考声场、具体拟音，还是整体氛围，不要把音色、节奏和内容混成一个职责。

## 多人物映射

多人时必须逐一绑定角色与参考素材。

推荐内部角色表：

`角色ID → 身份 → 参考素材 → 外观职责 → 其他职责`

不要只在图片中标名字，然后在 Prompt 里直接假设模型知道对应关系。

如果一位角色有多张视角图，明确这些图片属于同一角色，例如：

`@图片1、@图片2、@图片3均为角色A，只用于补充角色A不同视角的外观信息。`

## 参考职责隔离

优先避免以下情况：

- 人物图同时无边界地参考背景
- 场景图中的路人被继承为新角色
- 动作视频的人物服装或体型污染目标角色
- 运镜参考同时改变用户已经锁定的构图
- 音频节奏参考同时继承无关人声
- 同一角色的多张图被误识别为多个角色

当素材存在污染风险时，使用“允许参考 + 禁止迁移”成对表达，而不是只写模糊的“参考一下”。

## 素材职责优先级

如果不同素材在同一属性上冲突，优先依据用户明确指定的职责，而不是让模型自行融合。

例如：

- 图片1负责人物外观
- 图片2负责服装
- 图片3负责场景

则不要让图片1的服装和图片3的人物覆盖用户已经分配的职责。

## 与 Preflight 的分工

Asset Mapping 只回答：

`参考谁 / 参考什么 / 不参考什么`

Preflight 再检查：

- 素材职责之间是否冲突
- 人物数量是否一致
- 时间轴是否合理
- 镜头是否互斥
- 动作是否符合物理逻辑
- 连续性是否成立
- 声音是否冲突
- Prompt 密度是否过高

完整校验规则读取：`references/preflight-compiler.md`。
