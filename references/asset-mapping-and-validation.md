# 素材映射与 Prompt 校验

## 素材映射

每个素材都要回答三个问题：

1. 它是谁 / 是什么
2. 参考它的什么
3. 不参考它的什么

示例：

- `@图片1：主角外观参考，只参考脸型、五官、发型、服装和体型，不参考背景。`
- `@图片2：场景参考，只参考空间、构图、植物状态和光影，不参考其中人物。`
- `@视频1：只参考打斗动作、动作速度和镜头节奏，不参考角色外观。`
- `@音频1：只参考鼓点与卡点节奏，不参考其中人声。`

## 多主体

多人时逐一列清映射关系。不要只在图片里标名字然后在 Prompt 里直接使用名字。

如果一位角色有多张视角图，明确这些图片属于同一角色。

## Prompt 校验清单

### 参考关系
- 是否存在同一素材同时承担冲突职责？
- 是否写明部分参考的边界？

### 时间轴
- 是否连续？
- 单段是否信息过载？
- 是否存在动作在时间上不可能完成？

### 人物
- 人数是否固定？
- 是否出现角色复制风险？
- 左右位置与左右手是否前后一致？
- 未说话人物是否被误写成同步表演？

### 动作与物理
- 谁在做动作？
- 用哪只手 / 哪个方向？
- 接触、递物、摘取是否有交接过程？
- 局部受力是否被错误扩大成整体晃动？

### 镜头
- 运镜是否互相冲突？
- 是否同一时间要求推进、后拉、环绕等互斥动作？
- 转场是否有明确触发点？

### 声音
- BGM / 环境音 / 动作音 / 对白是否职责清楚？
- 声音是否绑定可见事件？
- 对白归属、顺序、音色是否明确？
- 字幕是否被当作对白的一部分而失去独立控制？

### 负向
- 是否只保留必要底线？
- 是否堆了大量与任务无关的负向词？

## 修复输出

当用户要求诊断时，按：

`问题 → 原因 → 修改策略 → 最终可复制 Prompt`

不要只指出问题而不给修复后的 Prompt。
